## 🛠️ Key Takeaways & Applied Concepts

### 1. Advanced Git Branching & Commit Hygiene

- **Feature Branching Strategy**: Bypassed direct commits to `main`. Built features sequentially using standard naming conventions (`feature/basic-calculator`, `feature/input-validation`, `docs/update-readme`).
- **Semantic Conventional Commits**: Used expressive commit tags (`feat:`, `fix:`, `docs:`) to ensure clarity in project history.
- **Repository Cleanliness**: Managed `.gitignore` to exclude build output files (`bin/`, `obj/`), IDE settings, and dynamic binaries.

### 2. Fork, SSH & Open Source PR Workflow

- **Authentication via SSH**: Configured SSH keys for securely authenticating Git operations with GitHub.
- **Fork & PR Lifecycle**: Forked the central class repository (`SimulationEG/github-contributors`), added a personalized developer portfolio page inside `students/omarsalem33/`, and submitted a clean Pull Request without modifying external files.

### 3. Problem Solving (LeetCode - Reverse String in C#)

- Applied the **Two Pointers Technique** on `char[]` to ensure **$O(1)$ Space Complexity** (In-place modification without standard library helper methods) and **$O(n)$ Time Complexity**.
